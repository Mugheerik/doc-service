# Doc Service — Backend

The backend API for Doc Service, built with FastAPI and Python. It handles authentication, document management, text extraction, AI analysis, and PostgreSQL persistence.

## Tech Stack

- Python 3.12
- FastAPI
- SQLAlchemy
- Alembic
- PostgreSQL
- JWT authentication
- Google Gemini API
- Pytest and Ruff

## Prerequisites

- Python 3.12
- [uv](https://docs.astral.sh/uv/)
- PostgreSQL, or Docker Compose from the repository root
- A configured Gemini API key

## Setup

From the `backend` directory:

```bash
uv sync --dev
```

Configure the environment variables in the root `.env` file. See the root [README](../README.md) for the configuration reference.

## Run Locally

From the `backend` directory:

```bash
uv run fastapi dev src/backend/main.py
```

The API is available at:

- API: http://localhost:8000
- Interactive documentation: http://localhost:8000/docs
- Health check: http://localhost:8000/health
- Database readiness: http://localhost:8000/health/ready

## Database Migrations

Apply existing migrations from the `backend` directory:

```bash
uv run alembic upgrade head
```

Create a migration after making model changes:

```bash
uv run alembic revision --autogenerate -m "describe your change"
```

Review autogenerated migrations before applying them.

## Tests and Code Quality

Run these commands from the `backend` directory:

```bash
uv run pytest
uv run ruff check .
uv run ruff format --check .
```

## Document Processing

The API accepts PDF, DOCX, and TXT documents up to 10 MB. It extracts text, submits the content for Gemini analysis, and stores the processing status and results in PostgreSQL.

Document processing failures are recorded against the corresponding document.
